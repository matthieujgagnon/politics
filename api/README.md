Backend service.

Implements the API defined in [`PROJECT.md`](../PROJECT.md) §17 (API specification), enforcing the permissions in §4 and the sourcing/epistemic-status rules in §12 at the data layer — not just in the frontend.

Starts empty. Phase 1 (§27) adds the service skeleton, auth, and the resource endpoints for whatever entities Phase 2 introduces.
